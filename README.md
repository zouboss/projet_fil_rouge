# 📘 Projet Fil Rouge - Projet fait l'ors de ma formation a la sonatel academie




---

## 🛠️ Stack technique

### Frontend
- [React.js](https://reactjs.org/)
- TailwindCSS  
- Axios, React Router

### Backend
- [Django](https://www.djangoproject.com/) & Django REST Framework

### Base de données
- PostgreSQL

### DevOps & Cloud
- [Docker](https://www.docker.com/)
- [Kubernetes (MicroK8s)](https://microk8s.io/)
- [Jenkins](https://www.jenkins.io/) pour le CI/CD
- [Ansible](https://www.ansible.com/) pour le déploiement automatisé
- [Prometheus](https://prometheus.io/) & [Grafana](https://grafana.com/) pour la supervision
- [Trivy Operator](https://aquasecurity.github.io/trivy-operator/) pour la détection de vulnérabilités
## 🚀 Objectifs

- Permettre aux utilisateurs de s'entraîner aux certifications (Cloud, DevOps, Développement…)
- Fournir une interface web fluide et responsive
- Offrir un back-office sécurisé pour la gestion des utilisateurs, questions, et résultats
- Mettre en œuvre les bonnes pratiques DevOps : CI/CD, monitoring, sécurité, infrastructure as code
---

## 📦 Fonctionnalités principales

- 🔐 Authentification des utilisateurs
  
- 🧪 CI/CD automatisé avec Jenkins
- ☁️ Déploiement conteneurisé avec Docker + Kubernetes
- 📈 Monitoring des services avec Prometheus + Grafana
- 🔐 Analyse de sécurité continue avec Trivy Operator
- ⚙️ Déploiement Kubernetes via Ansible
